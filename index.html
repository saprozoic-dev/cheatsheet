Who leads as bankroll grows

Starter $25: leads low, then fades. Commons cost just −$6.61, but hits are small (rares ~$70, epics ~$184, top $460) — can’t move a few-hundred bankroll.

Why the pick changes with bankroll

Sustain keeps you alive. Hit size moves you up. Strong on one usually = weak on the other.

Ranking = 30,000 sims per bankroll, counting how often each hits 2× before going broke. Weighs both automatically → best sustain ≠ best pick.

  1. Small bankrollFew packs, epics rarely land. Sustain wins.
  2. Large bankrollEnough packs for big tiers to hit. Hit size wins.

About the data

How it stays current
  1. Auto-updates 2×/day. Pulls the tracker → re-sims → republishes. “Updated” card amber/red = runs skipped.
  2. Source: Knut’s tracker (gap.knutegil.dev). Last pull Nov 22, 10:16 pm PT.
  3. Restock tell: common count ↑ + common avg ↓. Check uncommons too — a refill can drop commons but lift uncommons → better machine.
  4. Thin epic tiers swing hardest. Watch $500: 33 epics, Grail $1000: 40, Dragonball $250: 51, Pokémon $5000: 54. Watch the avg, not the count.
  5. Read time per machine in All machines. Older than the newest pull = amber.
